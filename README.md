# YoriMichi

ヨリミチAIは、徒歩・電車・車での移動中に、AIが選んだ近くのスポットを通知するスマホアプリのコンセプトデモです。東京周辺のシミュレーションルートとサンプルデータで、通知の流れをブラウザ上で体験できます。

## デモの使い方

公開 URL: https://kawarai-0855.github.io/YoriMichi/

1. スマホまたはパソコンのブラウザで、上の URL を開きます。
2. **シミュレーション**（初期状態）では、ルート（徒歩：浅草→上野／電車：山手線／車：新宿→八王子）と再生速度を選び、「再生」を押します。点が移動し、条件を満たすスポットの通知が届きます。
3. **実際のGPS** では、ブラウザの位置情報で現在地を追跡します。位置情報の取得には **HTTPS**（この GitHub Pages の URL など）または localhost が必要です。許可ダイアログで位置情報を許可してください。タブを閉じると追跡は止まります。

興味のあるジャンルは「興味・AI学習」タブで選べます。通知の「興味なし」を押すと、そのジャンルの優先度が下がる学習デモになっています。

## データについて

表示されるスポットは**サンプルデータ**です。「（サンプル）」付きの名称・説明は架空で、実在の店舗や営業情報ではありません。ルートも概略です。
