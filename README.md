# YoriMichi

ヨリミチAIは、徒歩・電車・車での移動中に、近くのスポットを通知するスマホアプリのコンセプトデモです。東京周辺のシミュレーションルートで、通知の流れをブラウザ上で体験できます。

公開 URL: https://kawarai-0855.github.io/YoriMichi/

## デモの使い方

1. スマホまたはパソコンのブラウザで、上の URL を開きます。
2. **シミュレーション**（初期状態）では、ルート（徒歩：浅草→上野／電車：山手線 東京→田端／車：新宿→道の駅 八王子滝山）と再生速度を選び、「再生」を押します。点が移動し、条件を満たすスポットの通知が届きます。
3. **実際のGPS** では、ブラウザの位置情報で現在地を追跡します。位置情報の取得には **HTTPS**（この GitHub Pages の URL など）または localhost が必要です。許可ダイアログで位置情報を許可してください。タブを閉じると追跡は止まります。収録スポットは上記ルートの周辺だけです。
4. **音声案内**は初期状態でオフです。ブラウザはユーザーの操作がないと音を出せないため、「音声案内：オフ」を押してオンにすると、短いテストのあと、通知のたびにスポット名と移動手段に応じた案内（徒歩の距離、次の駅、車での先の目安）を日本語で読み上げます。通知カードと履歴の「読み上げ」でもう一度聞けます。日本語の音声が端末にない場合は、その旨を表示し、読み上げは既定の声で試みます。

興味のあるジャンルは「興味・AI学習」タブで選べます。通知の「興味なし」を押すと、そのジャンルの優先度が下がる学習デモになっています。

## データについて

スポットは実行時に取得していません。OpenStreetMap の Overpass API から、各シミュレーションルートの範囲（浅草→上野、山手線 東京→田端の各駅周辺、新宿→道の駅 八王子滝山）にある名前付きの地点を取得し、`data.js` に静的データとして同梱しています（およそ250件。エリアが重なる地点は1件にまとめています）。カフェ、飲食店、史跡、公園・展望、博物館・美術館、商店、道の駅などを、アプリの既存カテゴリに対応づけています。名称は日本語名を優先しています。

営業時間や空室などのリアルタイム情報は含みません。ルートと駅の座標は概略です。
